DISPATCH WEBSITE - UPLOAD GUIDE (InfinityFree)

1. Log in to InfinityFree > Control Panel > Online File Manager (or use FTP).
2. Open the 'htdocs' folder. Delete the default index2.html if it is there.
3. Upload ALL the .html files from this folder directly into htdocs (not inside another folder).
4. Visit your domain. index.html is the home page.

Files: index.html (home), truck-sourcing.html, load-dispatch.html, loads-local.html, loads-outside.html,
login.html, signup.html, truck-30t.html, truck-superlink.html, truck-reefer.html, truck-notrailer.html,
truck-below30.html, truck-work.html, truck-sale.html
